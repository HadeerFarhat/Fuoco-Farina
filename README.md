# Fuoco Farina | فوكو فارينا

متجر إلكتروني فاخر — HTML · CSS · Vanilla JS

## التشغيل
فك الضغط → ادخل مجلد `fuoco-farina` → افتح `index.html`

أو: `python -m http.server 8080`
